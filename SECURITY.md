# Security policy

## Reporting a vulnerability

Please use GitHub's private reporting: on the repository page, open the Security tab and choose "Report a vulnerability". Please do not open a public issue for a security problem.

This is a solo-maintained project, so a reply can take a few days. I will confirm when I have read the report and tell you what I plan to do about it.

## What counts

These are workflow templates that people copy into their own repos, so the relevant problems are things like script injection through untrusted input, secrets exposed in logs, overly broad `permissions:`, or unpinned third-party actions. Reports about those are welcome.

## Supported versions

There is no release yet. Only the `main` branch is maintained.
